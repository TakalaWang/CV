# CV

One-page English CV for Chung-Chun (Takala) Wang, published at <https://takalawang.github.io/CV/>.

- Edit `cv.tex`, then push to `main`. GitHub Actions compiles it and deploys `Chung-Chun_Wang_CV.pdf` to Pages; `/CV/` redirects to the PDF.
- Local preview: `latexmk -pdf cv.tex` (keep it to one page).
- The full portfolio and case studies live at <https://takalawang.github.io/resume/>.

Layout: [Jake's Resume](https://github.com/jakegut/resume) by Jake Gutierrez (MIT), set on A4.
